# LIMINAL PROJECT — сайт V5

## Содержимое

- `index.html` — главная страница LIMINAL PROJECT: команда, проекты, контакты.
- `all-fiction.html` — страница ALL FICTION: реальный скриншот, возможности, требования, обзор, установка.
- `style.css` — единые стили двух страниц.
- `script.js` — мобильное меню, настройки скачивания и YouTube.
- `assets/` — **оригинальные предоставленные SVG** LIMINAL PROJECT, лого ALL FICTION и скриншот эмулятора.

В макетах не использованы случайные иконки или сторонние иллюстрации. Брендовые элементы — из загруженных SVG, рабочий скриншот — предоставленный.

## Публикация на GitHub Pages

1. Создай публичный репозиторий GitHub.
2. Загрузи **содержимое** архива в корень репозитория.
3. Открой `Settings` → `Pages` → `Deploy from a branch`.
4. Выбери `main`, `/ (root)` и сохрани.
5. Главная открывается через `index.html`, продукт через `all-fiction.html`.

## Настройка установщика и видео

В `script.js` поменяй:

```js
const SITE_CONFIG = {
  downloadUrl: 'https://example.org/ALL_FICTION_Setup.exe',
  youtubeVideoId: 'ВАШ_ID_РОЛИКА'
};
```

В `downloadUrl` укажи настоящую ссылку на ваш установщик. Если она пустая, кнопка открывает объясняющее окно с поддержкой и Telegram. `youtubeVideoId` — 11 символов из YouTube-ссылки `watch?v=...`. При пустом ID на странице показывается блок-заглушка.

Контакты: https://t.me/lmnprj, https://www.youtube.com/@lmnprj, lmnpr@proton.me

Системные требования на странице — ориентировочные данные базового MuMu Player, **не измерения ALL FICTION**. На странице указано происхождение сведений и приведена ссылка на оригинальную документацию.
